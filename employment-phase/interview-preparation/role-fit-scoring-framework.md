# Role-Fit Scoring Framework

This framework prioritizes effort; it does not predict hiring success.

Score each category from 0–3: 0 = unavailable, 1 = limited, 2 = reasonable with gaps, 3 = strong for current level.

| Category | Assessment | Score |
|---|---|---:|
| Experience fit | Does the experience requirement match my level? | 0–3 |
| Skill fit | Can I demonstrate required skills? | 0–3 |
| Education fit | Does my qualification meet the requirement? | 0–3 |
| Location/work eligibility | Can I meet the employer's requirements? | 0–3 |
| Portfolio relevance | Does evidence support the role? | 0–3 |
| Learning value | Does the role offer relevant development? | 0–3 |
| **Total** | Maximum 18 | **/18** |

## Guidance

- Compare the role with my actual RQF Level 3 Diploma in Cloud Cyber Security, completed in 2024 with 78%; do not claim automatic degree equivalence.
- Verify location, visa, work permit, NOC, and other eligibility requirements.
- Link every portfolio claim to a real file and label educational simulations honestly.
- Read the full job description before scoring.

## Priority Bands

| Total | Suggested Action |
|---:|---|
| 14–18 | Prioritize detailed review if eligibility is confirmed |
| 9–13 | Consider applying after reviewing major gaps |
| 0–8 | Apply only when there is a clear reason and no disqualifying requirement |
